# prompter-ai.moscow — сайт «Промптер»

Первый сайт компании. Живёт на своём хостинге, отдельном от genii-ai.ru:
папку `genii/` и её настройки он не затрагивает.

## Выложить на хостинг

Сайт обновляется одной командой в Shell-клиенте панели управления —
на том хостинге, где лежит prompter-ai.moscow:

```sh
sh -c "$(curl -sSL https://raw.githubusercontent.com/injusticebeast802-coder/taste-skill/main/prompter-moscow/hosting-ru/deploy.sh)"
```

Команда скачивает свежую версию сайта из репозитория и раскладывает её
в `~/www/prompter-ai.moscow`. Если папка называется иначе — допишите
`SITE_DIR=/полный/путь` перед командой.

Файл `config.php` с токеном бота создаётся один раз и переживает все
обновления: второй раз ключи вводить не надо.

У второго сайта команда своя, с `genii` вместо `prompter-moscow` в адресе,
и запускать её надо на втором хостинге.

## Страница «не найдено» (404)

Когда посетитель заходит по битой или старой ссылке, сервер по умолчанию
отдаёт белую страницу с надписью Not Found. Для сайта, который живёт
заявками, это прямая потеря клиента: человек просто закрывает вкладку.

Поэтому в папке сайта лежит `404.html` — та же тёмная страница в синей
палитре «Промптера», с кнопкой на главную, кнопкой «Оставить заявку» и
списком разделов. Включает её одна строка в `.htaccess`:

```
ErrorDocument 404 /404.html
```

Оба файла кладёт установка, руками ничего делать не надо. В конце скрипт
сам говорит, на месте ли страница.

**Как проверить после установки:** откройте в браузере любой несуществующий
адрес, например `prompter-ai.moscow/takoj-stranicy-net`. Должна открыться
тёмная страница сайта. Если открылась белая надпись Not Found — значит,
хостинг не читает `.htaccess`, и это вопрос в поддержку.

Все ссылки внутри `404.html` начинаются со слэша, и менять это нельзя.
Сервер отдаёт эту страницу в ответ на любой промах, в том числе на
`prompter-ai.moscow/uslugi/moskva/chego-to-net`. Относительная ссылка вида
`style.css` ушла бы тогда искаться в `/uslugi/moskva/style.css`, и
посетитель увидел бы голый текст без оформления.

## Что где лежит

* `index.html`, `style.css`, `script.js`, `form.js` — сам сайт;
* `zayavka.html` — отдельная страница формы, `privacy.html` — политика,
  `404.html` — страница «не найдено»;
* `hosting-ru/` — всё, что нужно только на хостинге: `.htaccess`,
  приём заявок `lead.php`, посредник для бота `tg.php`, образец настроек
  `config.example.php` и сам скрипт установки `deploy.sh`;
* `presentation/` — презентации по отраслям, установка кладёт их
  в папку `presentations` на сайте;
* `api/` — старый приём заявок для Vercel. На рег.ру не используется:
  там работает `hosting-ru/lead.php`.
