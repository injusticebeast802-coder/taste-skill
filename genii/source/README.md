# Исходники

Файлы, которые нужны для работы над сайтом, но не должны попадать
на сервер.

`logo-original.png` — логотип «ГенИИ» так, как его прислал заказчик:
1662 КБ, с непрозрачным фоном. Из него сделаны рабочие файлы в
`assets/`:

- `mark.png` — один знак, без фона, 208 пикселей. Шапка и подвал.
- `logo-full.png` — знак с надписью, без фона, 420 пикселей.
  Блок о полном цикле в секции «Наше решение».
- `favicon-64.png`, `icon-180.png` — значки вкладки и ярлыка.
- `og.png` — картинка для превью в мессенджерах, 1200×630.

Папка `source` намеренно лежит вне `assets`: скрипт установки
копирует на сервер `assets` целиком, и полуторамегабайтный исходник
уезжал бы туда при каждом обновлении, ничего не давая посетителю.
