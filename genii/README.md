# genii-ai.ru — сайт «ГенИИ»

Второй сайт компании. Полностью самостоятельный: папку `prompter-moscow/`
и всё, что связано с prompter-ai.moscow, он не затрагивает.

Что общего с первым сайтом:

* **тот же телеграм-бот и та же почта** для заявок — ключи берутся из тех же
  переменных `TG_TOKEN`, `TG_CHAT_ID`, `RESEND_API_KEY`, `MAIL_TO`, `MAIL_FROM`;
* заявки помечены строкой `genii-ai.ru` — в общем чате видно, с какого сайта пришла;
* те же шрифты и те же фотографии, кроме фото офиса и руководителя: их здесь нет.

Что отличается:

* название и логотип (`assets/logo.svg`);
* пастельная палитра: мята `#A8DCC8`, голубой `#A6D6E6`, лаванда `#C6B8E2`,
  розовый `#F0CCD2` на прежнем тёмном фоне. Все цвета заданы переменными
  в начале `style.css` — менять их надо там, в одном месте;
* акцент на генерации текстов, изображений и видео и на автопубликации
  на шести площадках (добавился Instagram, к нему обязательна сноска);
* точных цен на страницах нет: называется только экономия;
* страница короче примерно на четверть, презентаций по нишам нет.

## Выложить на хостинг

В Shell-клиенте панели управления:

```sh
sh -c "$(curl -sSL https://raw.githubusercontent.com/injusticebeast802-coder/taste-skill/main/genii/hosting-ru/deploy.sh)"
```

По умолчанию скрипт кладёт сайт в `~/www/genii-ai.ru`. Если папка называется
иначе — `SITE_DIR=/полный/путь` перед командой. Файл `config.php` с токеном бота
создаётся один раз и переживает все обновления.

## Заменить логотип

Логотип — векторный файл `assets/logo.svg`, он же иконка вкладки. Если нужен
другой знак, положите свой файл под этим же именем; растровые `favicon-64.png`,
`icon-180.png` и превью для соцсетей `og.png` пересобираются отдельно.
